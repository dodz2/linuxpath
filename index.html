Sandbox

$ Linux réel dans le navigateur

Un vrai noyau Linux (image de démonstration v86) exécuté en WebAssembly — aucune installation requise.

⚠️
Performances limitées sur mobile

La sandbox émule un processeur x86 complet via WebAssembly et charge ~6 Mo de Linux (image de démonstration v86). Les navigateurs mobiles manquent souvent de RAM et imposent des quotas WebAssembly qui peuvent empêcher le boot de se terminer.

Pour une expérience fiable, utilisez un ordinateur.

🐧 Linux x86 (v86) 🧠 v86 WASM JIT 🔒 Isolé dans votre navigateur
📂 Données nécessaires : Le démarrage télécharge environ 6 Mo (image Linux de démonstration v86). Comptez 30–60s pour le boot initial.
🔒 Sécurité : Tout s’exécute localement dans votre navigateur via WebAssembly. Aucune donnée n’est envoyée à un serveur.
📱 Mobile : le site (leçons, quiz, CTF) est utilisable sur téléphone. La sandbox est recommandée sur desktop.
