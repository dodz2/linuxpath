Sandbox

$ Linux réel dans le navigateur

Un vrai noyau Linux (Alpine) exécuté en WebAssembly — aucune installation requise.

🐧 Alpine Linux x86 🧠 v86 WASM JIT 🔒 Isolé dans votre navigateur
📂 Données nécessaires : Le démarrage télécharge environ 8 Mo (image Alpine Linux). Comptez 30–60s pour le boot initial.
🔒 Sécurité : Tout s’exécute localement dans votre navigateur via WebAssembly. Aucune donnée n’est envoyée à un serveur.
📱 Mobile : Fonctionne sur mobile mais les performances sont meilleures sur desktop.
